The two clean-discriminating items — based_on_schema and sibling_reserve_on_top — flip identically on both models: the agent always picks the wrong default alone (A=0) and with a decoy (B′=0), and always picks right with the real memory (B=1.0). The effect is the specific captured evidence, not any authoritative text — and it is model-independent.

Cross-model divergence:  fire_forget_entity is unknown to both a priori (A=0) → memory helps (+0.5 / +1.0).  ontology_default_on — gpt-5 guessed the old default; memory corrected it to the current one (+1.0). A different model surfaces more live items, not fewer.

Honest limits: small n (6 behavioral; only ~2–4 truly discriminate per model — the rest the model already knows, shown at A≈1). Single non-blind corpus author; post-hoc selection from 31 candidates. This is a behavioral-effect signal, not proof of net outcome value at scale. v1 failed a 4-lens adversarial review; this v2 adds the decoy control, a blind judge, and cross-model runs — which is why the numbers are trustworthy.
