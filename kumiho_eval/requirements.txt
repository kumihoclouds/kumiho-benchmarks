# >=0.18.0: the opt-in relation-decomposition stage (--decompose-relations)

# 0.19.0 extends that same agent's decomposition dict with belief-change
# lists (supersedes/contradicts) so the stage also writes SUPERSEDES/

# >=0.19.0 floor would break fresh installs before release. The belief-change
# keys ride inside the existing decomposition dict (no new call kwargs), so an
# 0.18.0 SDK ignores them and the stage degrades gracefully (belief counts
# stay 0). TODO(belief-change): bump this floor to >=0.19.0 once 0.19.0 ships
# to PyPI, so a run that expects belief edges fails fast on a too-old SDK.
